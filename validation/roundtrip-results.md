Each instance is read, written in SMPS by `write_smps` and read back, its probabilities as written and without `sense`, which the written core file must give. The problem read back must be the one read, every number exactly, every name the same but for those `write_smps` gives (the problem's, the right-hand side vector's, the scenarios' of a tree), the outcomes of a law completed with the values of the core file for the elements of their block they do not list, all of which `write_smps` lists; a scenario tree is compared as a stochastic program, by its data by scenario (`scenario_data`), the probabilities of its nodes and its bundles. The kind is that of the problem read: a two-stage problem (`SMPSProblem`), a scenario tree (`SMPSTree`) or a law by period (`SMPSStagewise`).
