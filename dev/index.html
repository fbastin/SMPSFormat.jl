SMPSFormat.jl

Read and write stochastic programs in the SMPS format: two-stage problems, and multistage ones given by their scenario tree or by a law for each period. The format is that of Birge et al. (1987), as Gassmann describes it and as Gassmann and Kristjánsson explain it (The SMPS format explained, IMA Journal of Management Mathematics, 2007, doi:10.1093/imaman/dpm007).

An instance in the SMPS format comes in three files:

  • the core file, the deterministic problem in MPS format;
  • the time file, which splits its columns and rows into periods;
  • the stoch file, the law of its random data: independent elements (INDEP), blocks of elements (BLOCKS), or the scenarios of a tree (SCENARIOS).

read_smps reads them into one of three types, according to what they describe:

The instanceThe typeWhat it gives
two periodsSMPSProblemthe matrices of each stage, the random elements and their law, an SMPSLaw
more periods, SCENARIOSSMPSTreethe core data and the scenario tree
more periods, INDEP and BLOCKSSMPSStagewisethe core data and a law for each period, independent from one period to the next

write_smps writes each back, and read_smps reads what it writes into the same problem. With JuMP loaded, extensive_form builds the deterministic equivalent.

Installation

The package is not registered yet; install it from its repository:

using Pkg
Pkg.add(url = "https://github.com/fbastin/SMPSFormat.jl")

A first example

LandS, the electricity capacity expansion problem of Louveaux and Smeers, in Felt's test set:

using SMPSFormat
data = joinpath(pkgdir(SMPSFormat), "test", "data")
smps = read_smps(joinpath(data, "lands"))     # lands.cor, lands.tim, lands.sto
SMPS instance LandS: 4 first-stage variables and 2 rows, 12 second-stage variables and 7 rows, 1 random elements (1 discrete blocks, 3 scenarios)

Its law is discrete; its three scenarios, and its deterministic equivalent solved with HiGHS:

using JuMP, HiGHS
(; ξ, p) = enumerate_scenarios(smps.law)
model, x, y = extensive_form(smps, ξ, p; optimizer = HiGHS.Optimizer)
set_silent(model)
optimize!(model)
objective_value(model)
381.8533333333333

The Guide goes through the rest: trees, laws by period, sampling, writing. The format says what the reader accepts and how it reads what the format leaves open, and Validation how it was checked against the optimal values published for the test collections of the literature.
