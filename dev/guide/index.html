Guide

The examples read the test data of the package, in test/data: data below is that directory.

Reading

read_smps takes the three files, or their common prefix: read_smps(prefix) looks for prefix followed by .cor or .core, .tim or .time, .sto or .stoch, each possibly compressed with gzip (.gz).

smps = read_smps(joinpath(data, "lands.cor"), joinpath(data, "lands.tim"), joinpath(data, "lands.sto"))
SMPS instance LandS: 4 first-stage variables and 2 rows, 12 second-stage variables and 7 rows, 1 random elements (1 discrete blocks, 3 scenarios)

An error names the file and its line. The options of the reader:

  • sense = :max reads the objective as a maximization, for files without OBJSENSE;
  • probability_sums says what to do with probabilities that do not sum up to one, as those written with a few digits (1/6 as 0.1667): normalize them when the gap is within their rounding (:rounding, the default), always (:normalize), or keep them (:as_written), as some of the published optimal values were computed;
  • format = :fixed reads the files in the columns of fixed MPS, so that names may contain blanks.

Two-stage problems

An SMPSProblem holds the data of each stage, c, A, b and q, T, W, h, and the random elements, elements, whose values ξ follow law. second_stage gives the data of the second stage for one ξ:

smps.elements
1-element Vector{Tuple{Symbol, Int64, Int64}}:
 (:h, 5, 0)
(; ξ, p) = enumerate_scenarios(smps.law)
second_stage(smps, ξ[1]).h
7-element Vector{Float64}:
 0.0
 0.0
 0.0
 0.0
 3.0
 3.0
 2.0

A discrete law can be enumerated, enumerate_scenarios; any law can be sampled:

rng = MersenneTwister(1)
ξs = rand(rng, smps.law, 1000)
length(ξs)
1000

extensive_form builds the deterministic equivalent for given scenarios, those of the law or a sample:

model, x, y = extensive_form(smps, ξs, fill(1 / 1000, 1000); optimizer = HiGHS.Optimizer)
set_silent(model)
optimize!(model)
objective_value(model)
380.59453333333664

Scenario trees

An instance in more periods whose stoch file gives its scenarios, SCENARIOS, is read into an SMPSTree: the core data, and the tree, each node with its period, its parent, its probability and the values of its random elements.

tree = read_smps(joinpath(data, "KandW3R"))
SMPS tree MYSMPS: 3 periods, 9 scenarios, 13 nodes (1, 3, 9 by period), 8 columns and 5 rows, 4 random elements

scenario_data gives the data of a scenario over all periods, bundles the scenarios that share a node in a period, those whose decisions must be equal:

bundles(tree, 2)
3-element Vector{Vector{Int64}}:
 [1, 2, 3]
 [4, 5, 6]
 [7, 8, 9]
scenario_data(tree, 1).rhs == scenario_data(tree, 2).rhs
false

The deterministic equivalent on the tree, in its nodal form, x[n] the variables of node n:

model, x = extensive_form(tree; optimizer = HiGHS.Optimizer)
set_silent(model)
optimize!(model)
objective_value(model)
2613.0000000000027

Laws by period

An instance in more periods whose stoch file gives INDEP and BLOCKS sections is read into an SMPSStagewise: a law for each period, independent from one period to the next. Its tree, the product of these laws, is not built when it is read: it may be far too large.

s = read_smps(joinpath(data, "pltexpa-3.cor"), joinpath(data, "pltexpa-3.tim"),
              joinpath(data, "pltexpa-3-6.sto"))
SMPS stagewise instance Prob_3: 3 periods (outcomes by period: 6, 6), 732 columns and 270 rows, 14 random elements
support_size(s)
36

scenario_tree builds the whole tree when it is small enough; sample_tree samples one, with a number of children for each period after the first:

tree = scenario_tree(s)
length(tree.scenarios)
36
sampled = sample_tree(MersenneTwister(1), s, [4, 3])
length(sampled.scenarios)
12

rand(rng, s) draws the values of the random elements in one scenario, and scenario_data gives its data.

A two-stage problem can be turned into a tree in two periods too, so that a code written for trees treats both:

scenario_tree(smps)
SMPS tree LandS: 2 periods, 3 scenarios, 4 nodes (1, 3 by period), 16 columns and 9 rows, 1 random elements

Writing

write_smps writes a two-stage problem (its law, or given scenarios), a tree, or a law by period, and returns the paths of the three files:

dir = mktempdir()
write_smps(joinpath(dir, "lands"), smps)
("/tmp/jl_oJcCEv/lands.cor", "/tmp/jl_oJcCEv/lands.tim", "/tmp/jl_oJcCEv/lands.sto")
write_smps(joinpath(dir, "sampled"), smps; scenarios = (ξ = ξs, p = fill(1 / 1000, 1000)))
read_smps(joinpath(dir, "sampled"))
SMPS instance LandS: 4 first-stage variables and 2 rows, 12 second-stage variables and 7 rows, 1 random elements (1 discrete blocks, 1000 scenarios)
write_smps(joinpath(dir, "sampled-tree"), sampled)
read_smps(joinpath(dir, "sampled-tree"))
SMPS tree Prob_3: 3 periods, 12 scenarios, 17 nodes (1, 4, 12 by period), 732 columns and 270 rows, 14 random elements
